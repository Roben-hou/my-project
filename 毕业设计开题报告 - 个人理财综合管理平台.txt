毕业设计开题报告
题目：个人理财综合管理平台的设计与实现

一、项目背景与意义
1.1 研究背景
随着我国经济的持续发展和居民收入水平的不断提高，个人理财需求呈现爆发式增长。根据中国人民银行发布的《2025 年中国居民金融素养调查报告》显示，我国居民投资理财参与率已达到 68.5%，较五年前增长了 23 个百分点。与此同时，投资渠道日益多元化，A 股市场、港股市场、美股市场以及各类基金产品成为普通投资者的主要选择。
然而，当前市场存在以下痛点：
1. 信息分散：投资者需要在多个平台之间切换，无法形成统一的资产视图
2. 数据滞后：大部分免费理财工具数据更新频率低，无法实现分钟级别的实时盈亏监控
3. 缺乏数据导出功能：现有理财工具不支持将资产数据导出为 Word 文档
4. 操作复杂：现有专业软件功能繁杂，学习成本高
1.2 研究意义
本项目旨在开发一款个人理财综合管理平台，集成港美股、A 股股票及基金功能，并创新性地加入表格数据导出 Word 功能。
理论意义：
* ? 探索多市场金融数据整合的技术方案
* ? 研究分钟级数据实时更新的前后端架构
* ? 研究 Web 端生成 Word 文档的技术实现
应用价值：
* ? 为个人投资者提供一站式资产管理工具
* ? 降低多市场投资的信息获取门槛
* ? 提供资产报表导出功能，满足用户多样化需求


二、项目目标
2.1 总体目标
设计并实现一个功能完善、数据实时、安全可靠的个人理财综合管理平台，支持用户统一管理 A 股、港股、美股及基金资产，实现分钟级别的盈亏实时更新，并提供资产数据表格导出 Word 文档功能。
2.2 具体目标
序号目标描述量化指标1实现港美股、A 股股票及基金的市场数据整合与实时展示支持不少于 3 个市场，数据更新延迟<1 分钟2开发用户资产手动导入功能支持 Excel、CSV 等多种格式导入3构建分钟级别的资产盈亏实时更新系统数据更新频率≤1 分钟/次4设计直观的资产可视化仪表盘包含不少于 5 种图表类型5实现表格数据导出 Word 功能支持持仓明细、盈亏报表导出，表格样式美观
三、主要功能模块设计
3.1 系统架构
系统采用前后端分离架构：前端使用 Vue3 + ElementPlus 构建用户界面，后端使用 Node.js + Express.js 提供 RESTful API，数据库使用 MySQL 8.0 存储数据。
3.2 核心功能模块
模块名称功能描述市场行情模块实时展示港美股、A 股及基金市场数据，包括多市场指数看板、自选股列表等资产管理模块支持手动导入、分类管理各类金融资产，支持 Excel/CSV 批量导入盈亏分析模块实现分钟级更新的资产盈亏计算与展示，包括收益率分析、盈亏排行榜等数据可视化模块通过 ECharts 图表库展示资产配置饼图、收益走势折线图等表格导出 Word 模块将资产数据表格导出为 Word 文档，支持自定义样式和格式

四、技术方案
4.1 前端技术栈
前端采用现代化的 Vue3 技术栈，具有学习曲线平缓、开发效率高、生态丰富等优点。
技术选型说明前端框架Vue 3渐进式 JavaScript 框架，易学易用UI 组件库Element Plus基于 Vue3 的组件库，组件丰富HTTP 客户端Axios简洁的 HTTP 请求库，支持拦截器构建工具Vite下一代前端构建工具，开发服务器启动快图表库ECharts功能强大的数据可视化图表库Word 导出docxJavaScript 编写的 Word 文档生成库状态管理PiniaVue3 官方推荐的状态管理库
4.2 后端技术栈
后端采用 Node.js + Express.js 技术栈，使用 JavaScript 统一前后端语言，降低学习成本。
运行环境Node.jsJavaScript 运行时，跨平台Web 框架Express.js轻量级 Web 框架，灵活简单数据库MySQL 8.0成熟的关系型数据库，文档丰富ORMSequelize基于 Promise 的 MySQL  ORM 库认证JWT无状态的身份验证方案密码加密bcryptjsJavaScript 实现的密码加密库
4.3 系统架构图
系统采用经典的前后端分离三层架构：

采用定时任务 + 缓存的方式实现分钟级数据更新：
